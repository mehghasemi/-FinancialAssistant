# قرارداد API نسخهٔ 0.7.0

همهٔ تاریخ‌های قابل مشاهده و ورودی API شمسی و به‌شکل `YYYY/MM/DD` هستند؛ برای نمونه `۱۴۰۵/۰۶/۲۸`. ماه‌های فیلتر API با کلید `YYYY-MM` ارسال می‌شوند و رابط، آن‌ها را با نام فارسی مانند «شهریور ۱۴۰۵» نشان می‌دهد. تاریخ میلادی فقط در دیتابیس داخلی نگهداری می‌شود. مبلغ‌ها عدد صحیحِ مثبت و در واحد پول تنظیم‌شدهٔ برنامه‌اند.

| مسیر | روش | کاربرد |
|---|---|---|
| `/api/health` | GET | وضعیت برنامه و دیتابیس |
| `/api/accounts` | GET | فهرست حساب‌ها |
| `/api/categories` | GET | فهرست دسته‌ها |
| `/api/transactions` | GET/POST | خواندن یا ثبت درآمد و هزینه |
| `/api/commitments` | GET/POST | فهرست تعهدهای پایه یا ساخت تعهد و اقساط آن |
| `/api/commitments/preview` | POST | پیش‌نمایش اقساط قبل از ثبت |
| `/api/commitments/{id}` | PATCH | ویرایش یک ریزتعهد |
| `/api/commitments/{id}/group` | PATCH | ویرایش عنوان و نوع همهٔ ریزتعهدهای هم‌عنوان |
| `/api/installments` | GET | سررسیدها با فیلتر ماه و وضعیت |
| `/api/installments/{id}` | PATCH | ویرایش جزئیات یک قسط |
| `/api/installments/{id}/details` | GET | ریز پرداخت‌ها و تاریخچهٔ تغییرات |
| `/api/payments` | POST | ثبت پرداخت کامل یا جزئی |
| `/api/payments/{id}` | PATCH/DELETE | اصلاح یا حذف پرداخت ثبت‌شده |
| `/api/dashboard` | GET | شاخص‌های ماهانه |
| `/api/releases` | GET | تاریخچهٔ نگارش‌ها |

### خطاها

ورودی نامعتبر پاسخ `422` و پیام فارسی دارد. خطای داخلی پاسخ `500` با `error_id` برمی‌گرداند؛ جزئیات داخلی یا stack trace به رابط کاربری ارسال نمی‌شود.
